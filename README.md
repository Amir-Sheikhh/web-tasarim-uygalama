# web-tasarim-uygalama
🚀 Sınıf Not Defteri (Ultra Pro)
A modern, real-time class notebook application built with Vanilla JavaScript and Firebase. This project features a sleek "Dark Mode" UI, category management, drag-and-drop organization, and live updates.

✨ Features
🎨 Ultra Modern UI: A fully responsive "Dark Mode" interface inspired by glassmorphism and neon aesthetics (Black & Purple theme).

🔥 Real-time Database: Powered by Firebase Firestore, changes (adds, edits, deletes) appear instantly for all users without refreshing.

📂 Group & Categorize: Organize notes into categories like Homework, Exam, Project, etc.

🖱️ Drag & Drop: Intuitive drag-and-drop functionality to move notes between categories instantly.

✏️ CRUD Operations: Full capability to Create, Read, Update, and Delete notes.

🔍 Live Search: Filter notes by title, content, or category in real-time.

📱 Mobile Responsive: Works perfectly on desktops, tablets, and mobile phones with a sidebar layout.

🛠️ Technologies Used
HTML5 & CSS3 (Custom Flexbox/Grid Layouts)

JavaScript (ES6+)

Firebase SDK v11 (Firestore, Realtime Updates)

Inter Font (Google Fonts)

🚀 Getting Started
Prerequisites
You need a Firebase project to run this app.

Go to the Firebase Console.

Create a new project.

Enable Firestore Database in "Test Mode" (or set up proper security rules).

Copy your firebaseConfig object.
